🛡️ 2. SQLAlchemy Raw Query Warning Fix

Masalah:

Terdapat peringatan dari SQLAlchemy karena penggunaan raw SQL yang tidak aman

Solusi yang diharapkan:

Cek dan refactor semua query seperti:

python
Salin
Edit
db.execute("SELECT * FROM transactions WHERE ...")
Ubah ke:

python
Salin
Edit
from sqlalchemy import text
db.execute(text("SELECT * FROM ..."))
Atau lebih baik: gunakan ORM-style dengan session.query() atau select()
